根据您上传的论文《Causal Evaluation of Language Models》，这几个类型的数据集属于 **CaLM 框架** 中 **因果阶梯（Causal Ladder）** 的 **第二层级（Rung 2）：干预（Intervention）**。

这一层级主要关注“行动”（Doing）的效果。与仅仅观察数据（Rung 0 & 1）不同，这一层级要求模型预测**人为干预**或**改变**某个变量后产生的结果（即处理形如“如果我做了这件事，会发生什么？”的问题）。

以下是各个数据集的详细解释：

### 1. Average Treatment Effect (ATE, 平均处理效应)

* **定义**：量化特定干预措施对群体的平均影响。它通过比较“处理组”（接受干预）和“控制组”（未接受干预）之间的结果差异来计算。
* *公式概念*：。


* **数据集场景设置**：
* **输入**：一个自然语言描述的因果图（例如：“每周锻炼量直接影响身体健康水平……”）以及相应的条件概率数据。
* **任务**：
1. **二分类**：回答 Yes/No 问题，例如“如果把锻炼量改为‘很少’，身体健康水平变为‘优秀’的可能性会更大吗？”
2. **概率计算**：利用给定的概率数据，精确计算出 ATE 的数值（保留四位小数）。


* **例子**：评估某项就业政策对失业时长的平均影响。



### 2. Backdoor Adjustment Set (BAS, 后门调整集)

* **定义**：基于 Pearl 的“后门准则”（Back-door criterion）。为了准确估计 X 对 Y 的因果效应，必须阻断所有从 X 指向 Y 的“后门路径”（即由混杂因子导致的非因果关联路径）。BAS 就是这样一组需要被控制（Condition on）的变量集合。
* **数据集场景设置**：
* **输入**：一个符号化的因果图（如“A causes B, B causes D...”）。
* **任务**：
1. **选择题**：给定一对变量（如 D 和 E），要求找出满足后门准则的变量集合（分为最大集、最小集和混合集）。
2. **二分类**：判断两种分析方法哪种更正确（例如：“是应该直接看相关性，还是应该根据某个变量分情况看？”）。





### 3. Frontdoor Adjustment Set (FAS, 前门调整集)

* **定义**：基于 Pearl 的“前门准则”（Front-door criterion）。当存在**未观测到的混杂因子**导致无法使用后门准则时，如果存在一个中间媒介（Mediator）能够传递因果影响，我们可以通过该媒介来分步估计因果效应。
* **数据集场景设置**：
* **输入**：一个符号化的因果图。
* **任务**：**选择题**。给定一对变量（如 A 和 D），模型需要识别出满足前门准则的变量集合。
* **意义**：这在很多无法进行随机对照试验的领域（如社会政策、流行病学）非常关键，用于在有隐藏混杂因素时估计因果。



### 4. Instrumental Variable (IV, 工具变量)

* **定义**：工具变量 Z 是一个特殊的变量，它满足两个条件：(1) 与未观测的混杂因子独立；(2) 与处理变量 X 相关，且只通过 X 影响结果 Y。
* **数据集场景设置**：
* **输入**：一个符号化的因果图。
* **任务**：**选择题**。给定一对变量（如 B 和 D），要求模型识别出哪个变量是工具变量。
* **例子**：研究“教育”对“收入”的影响，能力（未观测混杂因子）同时影响两者。这时，“大学距离”（Instrumental Variable）可以作为一个工具变量，因为它影响你是否上大学，但理论上不直接决定你的收入。



### 5. Collider Bias (CB, 对撞偏差)

* **定义**：当两个独立的变量（A 和 B）共同导致第三个变量（C）时，C 被称为“对撞点”（Collider）。如果在分析中**控制**或**观察**了 C（即把 C 当作条件），原本独立的 A 和 B 就会变得相关。这种虚假的相关性被称为对撞偏差。
* **数据集场景设置**：
* **输入**：描述因果关系的文本和概率（例如：“呼吸问题导致住院。骨折导致住院。在住院病人中，呼吸问题和骨折的相关性是 -0.01”）。
* **任务**：**二分类**。模型需要排除对撞偏差的干扰，正确回答变量之间原本的关系。例如：“如果我们只看住院的人，是否意味着呼吸问题不影响骨折？”（在这个特定设置下，目的是测试模型能否意识到观测特定子集（住院者）会扭曲变量间的真实独立性）。
* *经典例子*：好莱坞演员的“才华”和“颜值”。如果只看成名演员（即控制了结果），会发现颜值和才华呈负相关，这是一种偏差。



### 6. Causal Effect Identification (CEI, 因果效应识别)

* **定义**：判断在给定的因果图和观测数据分布下，某个因果效应（例如 ）是否在理论上是**可计算的**（Identifiable）。
* **数据集场景设置**：
* **输入**：
1. 一个符号化的因果图（如“A causes B...”）。
2. 明确指出**存在未观测的混杂因子**（Unobserved Confounders），并设定不同的比例（如 20%, 40% 的节点对之间存在混杂）。


* **任务**：**二分类**。判断指定的一对处理-结果变量之间的因果效应是否可以被识别（Identified）。
* **意义**：这是因果推断的第一步，决定了是否值得去收集数据进行计算。



### 7. Controlled Direct Effect (CDE, 控制直接效应)

* **定义**：衡量处理变量（X）对结果（Y）的**直接**影响，同时将中间媒介变量（M）**固定**在某个特定水平。这旨在剥离掉通过媒介传递的间接影响。
* **数据集场景设置**：
* **输入**：自然语言描述的因果图和概率（例如：教学策略 -> 学生自信心 -> 考试成绩；教学策略 -> 考试成绩）。
* **任务**：
1. **二分类**：回答形如“在控制了降雨量（媒介）为小的情况下，如果天气变好，作物产量变高的可能性会更大吗？”的问题。
2. **概率计算**：计算具体的 CDE 数值。

总结来说，这一层级的数据集从简单的干预效果计算（ATE），到处理复杂的混杂因素（BAS, FAS, IV, CB），再到理论上的可识别性判断（CEI）和细粒度的直接效应分析（CDE），全面评估了模型在因果干预层面的推理能力。
