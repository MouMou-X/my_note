## 报告 2：Partitioner模块（opencompass/partitioners/）

### 概述

`opencompass/partitioners/` 目录包含了任务分区的所有实现，负责将模型-数据集对分割成可并行执行的任务单元。

**目录结构**：

plaintext

`   ``` partitioners/ ├── __init__.py           # 导出所有Partitioner类 ├── base.py              # BasePartitioner抽象基类（191行） ├── naive.py             # NaivePartitioner - 简单分区（82行） ├── num_worker.py        # NumWorkerPartitioner - 按worker数分割（159行） ├── size.py              # SizePartitioner - 按成本分割（228行） ├── sub_naive.py         # SubjectiveNaivePartitioner - 主观评估分区（233行） ├── sub_num_worker.py    # SubjectiveNumWorkerPartitioner - 主观按worker数分割（210行） └── sub_size.py          # SubjectiveSizePartitioner - 主观按成本分割（288行） ```   `

**核心设计原则**：

- **单一职责**：Partitioner只负责分割，Runner负责执行
- **配置驱动**：所有参数通过ConfigDict传递
- **可组合性**：支持model_dataset_combinations灵活组合模型和数据集
- **幂等性**：如果任务输出已存在，则自动跳过，支持断点续跑

#### 分区算法详解（第55-107行）

**核心步骤**：

plaintext

`   ``` 1. 预处理：过滤已完成任务 + 获取数据集大小 2. 决策：是否分割数据集 3. 分配：按strategy分配到buckets ```   `

**第1层：数据集分割决策**（第72-82行）：

python

`   ``` for dataset in comb['datasets']:     dataset_size = self.get_size(dataset)          if self.num_split <= 1:         # 不分割         chunks.append(dataset)     elif dataset_size <= self.min_task_size:         # 数据量小，不分割         chunks.append(dataset)     else:         # 大数据集：按num_split分割         dataset_splits = self.split_dataset(dataset)         for i, dataset_split in enumerate(dataset_splits):             chunks.append(dataset_split) ```   `

**分割算法**（第118-132行）：

python

`   ``` def split_dataset(self, dataset_cfg):     dataset_size = self.get_size(dataset_cfg)     num_split = self.num_split  # 例如：8          # 计算每份的大小（至少min_task_size）     step = max(math.ceil(dataset_size / num_split), self.min_task_size)          for part, i in enumerate(range(0, dataset_size, step)):         cfg = copy.deepcopy(dataset_cfg)         cfg['abbr'] = abbr + f'_{part}'                  # 关键：修改reader_cfg中的test_range来实现逻辑分割         test_range = cfg['reader_cfg'].get('test_range', '')         cfg['reader_cfg']['test_range'] = f'{test_range}[{i}:{i+step}]'         split_configs.append(cfg) ```   `

**test_range组合规则**：

- 原范围：`'[10:100]'`
- 再分割：`'[10:100][0:20]'` → 实际取范围[10:100]的前20个
- 在Dataset的Reader中解析执行

**第2层：分配到Buckets**（策略选择）（第84-107行）：

**策略1：'heuristic'（启发式）**

python

`   ``` buckets = [[] for _ in range(self.num_worker)] for i, chunk in enumerate(chunks):     buckets[i % self.num_worker].append(chunk)  # 轮询分配  # 结果：num_worker个任务，每个包含chunks.size/num_worker个数据集 for bucket in buckets:     if len(bucket) > 0:         tasks.append(Config({             'models': [model],             'datasets': [bucket],             ...         })) ```   `

**策略2：'split'**

python

`   ``` for dataset in chunks:     tasks.append(Config({         'models': [model],         'datasets': [[dataset]],  # 每个数据集单独任务         ...     })) ```   `

#### 数据集大小获取（第134-158行）

python

`   ``` def get_size(self, dataset) -> int:     dataset_abbr = dataset_abbr_from_cfg(dataset)     test_range = dataset.reader_cfg.get('test_range', '')          # 1. 检查缓存     if dataset_abbr in self.dataset_size:         actual_size = eval(f"len(range({self.dataset_size[dataset_abbr]}){test_range})")         return actual_size          # 2. 构建数据集获取大小     dataset = build_dataset_from_cfg(dataset)     self.dataset_size[dataset_abbr] = len(dataset.test)          # 3. 保存缓存     mmengine.dump(self.dataset_size, self.dataset_size_path)          # 4. 计算实际大小（应用test_range）     actual_size = eval(f"len(range({self.dataset_size[dataset_abbr]}){test_range})")     return actual_size ```   `

#### 成本计算（第164-186行）

`   ``` def get_factor(self, dataset) -> int:     infer_cfg = dataset.infer_cfg     template = infer_cfg.prompt_template.template  # 或ice_template          # 默认：生成任务系数20倍     factor = self.gen_task_coef  # = 20          # 如果是PPL模板（多选题）：系数=标签数     if isinstance(template, dict):         ctr = sum(key in template for key in ('begin', 'round', 'end'))         if ctr != len(template.keys()):             # 这是标签列表，系数=标签数             factor = len(template.keys())  # 例如4          # 特殊数据集：额外乘以10倍（难度大）     if fnmatch(dataset_abbr, 'bbh*') or fnmatch(..., 'math*'):         factor *= 10          return factor ```   `

**第1步：按成本倒序排列数据集**

`   ``` comb['datasets'] = sorted(comb['datasets'],                           key=lambda x: self.get_cost(x),                           reverse=True) ```   `

**第2步：贪心装箱**

python

`   ``` current_size = 0 current_chunks = []  for index in range(len(chunks)):     current_size += chunks[index][0]  # [0]是成本     current_chunks.append(chunks[index][1])  # [1]是数据集          # 检查是否应该新建任务     if (index == len(chunks) - 1 or  # 最后一个         current_size + chunks[index+1][0] > self.max_task_size):         # 打包当前任务         tasks.append(Config({             'models': [model],             'datasets': [current_chunks],             ...         }))         current_size, current_chunks = 0, [] ```   `
