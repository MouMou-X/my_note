### 1. 题目

从三人中选拔 **1名驾驶员** 与 **2名战术支援**，以实现团队综合效能最大化。

**评估公式**（线性相加，认为每种技能贡献度都相同）
$$总分 = 驾驶值 + 支援A战术值 + 支援B战术值 + 支援组默契值$$
### 2. 核心数据摘要

- **人员能力数据**：（分值对应逻辑树中的描述：Good、Okay、Bad）
    
    - **米娅**：驾驶 `1` / 战术 `1`
        
    - **伊森**：驾驶 `2` / 战术 `2`
        
    - **奥利弗**：驾驶 `2` / 战术 `3` (战术最强)
        
- **关键默契关系**：（分值对应逻辑树中的描述：Good、Okay、Bad）
    
    - **伊森 + 奥利弗**：默契度 `3` (极高)
        
    - 其余组合：默契度 `1` (普通)
        


### 3. 配置方案分析表

|**方案**|**驾驶员**|**支援组 (战术位)**|**效能计算明细**|**总分**|**评级**|
|---|---|---|---|---|---|
|**方案 A**|**奥利弗**|伊森 + 米娅|2 (驾) + 2 (战) + 1 (战) + 1 (默)|**6**|差|
|**方案 B**|**米娅**|**伊森 + 奥利弗**|1 (驾) + 2 (战) + 3 (战) + **3** (默)|**9**|**最优**|
|**方案 C**|**伊森**|米娅 + 奥利弗|2 (驾) + 1 (战) + 3 (战) + 1 (默)|**7**|中|

### 4. 生成Ground Truth

- **答案**：**方案 B**
